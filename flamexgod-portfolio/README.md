# FLAMExGOD Portfolio - Diparsan Pathak

A modern, dark-themed portfolio website showcasing my coding journey as a beginner programmer and Python learner.

## 🚀 Features

- **ASCII Intro Animation**: Custom "DIPARSAN" ASCII art with smooth transitions
- **Dark Futuristic Theme**: Sleek design with gradient accents and glow effects
- **Smooth Animations**: Powered by Framer Motion for fluid user experience
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Accessibility First**: WCAG compliant with keyboard navigation and screen reader support
- **Performance Optimized**: Fast loading with code splitting and lazy loading
- **Modern Tech Stack**: Built with React, TypeScript, and Vite

## 🛠️ Tech Stack

- **Framework**: React 18+ with TypeScript
- **Build Tool**: Vite
- **Animations**: Framer Motion
- **Styling**: CSS Custom Properties with responsive design
- **Deployment**: Vercel
- **Performance**: Code splitting, lazy loading, and optimization

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Diparsan79/flamexgod-portfolio.git
cd flamexgod-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

### Building for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 📝 Content Management

All content is stored in separate data files for easy editing:

- `src/data/skills.ts` - Technical skills and proficiency levels
- `src/data/projects.ts` - Portfolio projects and descriptions
- `src/data/timeline.ts` - Coding journey milestones
- `src/data/contacts.ts` - Social links and contact information

Simply edit these files to update the website content without touching the components.

## 🌐 Deployment

The site is configured for easy deployment on Vercel:

1. Connect your GitHub repository to Vercel
2. Vercel will automatically detect the Vite configuration
3. Deploy with zero configuration needed

### Manual Deployment

```bash
npm run build
# Upload the 'dist' folder to your hosting provider
```
